**踩坑记录**：
- pnpm 在 Windows CodeBuddy 有 safe-delete shim 冲突（本地构建会报错但产物正常；服务器无此问题）
- node 服务在 type:module 项目下要命名 .cjs
- systemd `Environment=BUILD_CMD=pnpm build` 的空格必须加引号 `Environment="..."`，否则环境变量解析成两个
- spawn('pnpm',['build']) 数组形式比 shell 模式可靠
- ssh 命令转义：PowerShell 中复杂命令用 base64 传输最稳；heredoc 会被转义破坏
- nginx 备份文件放 sites-enabled 会冲突（default_server 重复），要移出
