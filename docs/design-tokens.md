# 云笺集 · 设计令牌（Design Tokens）规范

> 设计语言：**晨海蓝 + 玻璃拟态 + 未来科技感**。一切视觉样式通过 CSS 变量（令牌）表达，组件禁止硬编码颜色；主题切换只换变量、不动骨架。

## 1. 令牌分层

| 层       | 载体                                                         | 说明                                  |
| ------- | ---------------------------------------------------------- | ----------------------------------- |
| L0 全局令牌 | `:root`（[main.css](../apps/workbench/src/styles/main.css)） | 亮色默认值，所有页面共享                        |
| L1 暗色覆盖 | `[data-theme='dark']`                                      | 切换 `<html data-theme='dark'>` 即整体换肤 |
| L2 组件主题 | `[data-theme='<variant-id>']` 注入 CSS 变量                    | 「骨架不变 · 样式抽离」，见 §4                  |

## 3. 使用规则

1. **一律** **`var(--x)`** **引用**，组件/页面禁止硬编码色值；确需临时色用 `color-mix(in srgb, var(--x) p%, transparent)`。
2. **暗色覆盖成对维护**：新增带背景/文字颜色的样式时，必须同时提供 `[data-theme='dark']` 覆盖（如 `.shead` 的暗色渐变背景），否则视为漏网补丁。
3. **状态徽章**统一语义 chip：`.pill.ok` / `.pill.warn` / `.pill.danger`（背景用对应 `*-muted`，文字用语义色）。勿为同义状态各造一套色。
4. **无障碍动效**：装饰性动画（气泡浮动/入场弹跳/粒子漂移）在 `prefers-reduced-motion: reduce` 下全局停用（main.css 末尾 block），新动画无需重复写该媒体查询。
5. **主题切换**：偏好页写 `<html data-theme='dark'>`，`color-scheme: dark` 同步；令牌即换肤的全部开关。

## 4. 组件主题系统（骨架不变 · 样式抽离）

实现：[componentTheme.ts](../apps/workbench/src/lib/componentTheme.ts)

- **概念**：任何「骨架固定、外观可换」的组件，注册一组 `ThemeVariant[]`（id/标签/说明/预览色）；组件根节点按偏好渲染 `data-theme={id}`，CSS 以 `[data-theme='...']` 只覆盖视觉层，骨架样式不动。

- **持久化键**（localStorage）：

  - 组件主题：`cl_theme_<key>`

  - 布局主题：`cl_theme_layout_<key>`

  - 日期独立主题：`cl_day_theme_<yyyy-mm-dd>`（未覆盖的日期自动跟随全局）

- **主题组**：

| 组      | key          | 变体                              |
| ------ | ------------ | ------------------------------- |
| 日期选择胶囊 | `capsule`    | 9 套：玻璃/实心/主蓝/墨黑/极光/深海/松林/薄荷/白描边 |
| 日常卡片   | `dailyCard`  | 标准/毛玻璃/主蓝/墨绿/深蓝                 |
| 检索卡片   | `searchCard` | 纯白/浅灰/毛玻璃/嵌套                    |
| 目标行    | `goalsRow`   | 纯色/描边/毛玻璃/条纹                    |
| 文章列表   | `postList`   | 清爽/卡片/浅灰                        |
| 组织看板   | `orgKanban`  | 清爽/卡片/毛玻璃                       |
| 番茄专注   | `pomodoro`   | 主蓝/番茄红/活力橙/墨绿/深海/琥珀/薄荷          |

**新增组件主题的步骤**：① 追加一组 `ThemeVariant[]`；② 组件根节点渲染 `data-theme={id}`；③ 补一组 `[data-theme='...']` CSS 变体；④ 设置页用带色块的 `ThemeSelect` 接入。框架无需改动。

**日期独立主题**：每个日期可单独覆盖胶囊主题（`writeDayTheme(ymd, id)`），`''/null` 恢复跟随全局；`listDayThemes()` 汇总全部覆盖，`clearDayThemes()` 一键复位。

## 5. 对比度与可访问性

- `--text-tertiary` 已按 WCAG 调优：亮色 `#7c8fb0`→`#5a6d8f`（白底约 5.2:1）、暗色 `#6d80a3`→`#7a8eb0`（`#0d1420` 上约 5.6:1），辅助说明小字不再发虚。

- 状态色用于正文/徽章时保证与背景 ≥4.5:1；仅装饰性元素允许低对比。

- 键盘可达：所有主题切换/下拉均为原生控件，`aria-label` 齐备；专注模式提供 Esc 退出提示。

## 6. 变更规范

- 改令牌值：只在 `:root` 与 `[data-theme='dark']` 两处改，全局生效，不散改页面。

- 新增令牌：按上述分类就近添加，并在本节补齐「亮色/暗色/用途」三列；同步更新本文件。

- 删除令牌：先 `rg "var(--x)"` 确认无引用再删。

- 硬编码颜色长尾：发现一处，能令牌化即令牌化；确属一次性场景（导出打印、粒子装饰、SVG 色块）可保留并在注释说明。
