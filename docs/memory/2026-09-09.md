
# 2026-09-09（一）：计划/目标/习惯/工作计划编辑器同款根治（已上站）

## 用户反馈

计划、目标、习惯三处（新建/编辑）的编辑器也有灵感笔记同款的「打字被撤销」问题。

## 排查与修复

- 全站 `<MarkdownEditor` 扫描：受控残留共 4 处——PlanPage（今日计划抽屉）、WorkPlanPage（工作计划 Modal 弹窗）、GoalsPage（目标抽屉）、CheckinPage（习惯抽屉），此前同类修复只覆盖了灵感笔记/速记两处。
- 四处统一改 `uncontrolled`（value 仅初值、关闭即卸载重开取新初值，外部永不回灌）；编辑器 Field 加 `as="div"`（label 焦点转发劫持 contenteditable，实测点击落点失效的帮凶）；minHeight 240/220 → 120（drawer/modal 内 bn-container 压平规则已有，正文贴合保存分割线）。
- 四处均为条件渲染（`{drawerOpen && <Drawer>}` / `{formOpen && <Modal>}`），uncontrolled 初值语义成立。

## 双击选区对照实验（Playwright + Node 直驱 Playwright-core）

- 纯 contenteditable 双击选「计划」（2 字）；BlockNote 双击选「回顾」（2 字）——**双击选词两者均正常**。
- 4 连击两者均选整段——**浏览器原生多击计数（2击词→3击句→4击段），Notion 同款行为，非本站缺陷**。此前实测的"双击大选中"实为测试序列"单击放光标+双击"= 三连击所致。
- 真实数据丢失风险已由 uncontrolled（无回灌）+ replaceFromMarkdown 迟到落地守卫（lastUserEditAt）双重阻断。

## 补充：编辑器高度改为填满表单+内部滚动（同日）

- 用户再反馈：随手记等编辑抽屉内容区较矮、下方大片空白。要求编辑器填满表单到底部分割线、内容超出时内部滚动。
- 实现（纯 CSS，:has() 项目已有使用）：.drawer-body:has(.mded) / .modal:has(.mded) 变纵向 flex；含编辑器的 .mfield:has(.mded) flex:1；高度链 .mded→.ed-blocknote→.bn-container 全 flex column min-height:0，.bn-editor flex:1 + overflow-y:auto（min-height 120 保底）。Modal 补 max-height calc(100vh-48px)+overflow:auto、.mh/.mfoot flex-shrink:0。
- 实测（Node 直驱 playwright-core）：随手记/计划抽屉空态编辑器 423px 恒定、底边距分割线 19px 不随内容变化；810 字输入内容高 547>423 时编辑器内部滚动、抽屉 body 不滚。Modal（工作计划）高度由内容决定时编辑器紧贴分割线（gap 23px=footer margin，无空白），超视口时 max-height+内部滚动兜底。
- 影响面：所有含编辑器的抽屉/弹窗（随手记/计划/目标/习惯/工作计划/速记汇总）；文章编辑页（非抽屉/弹窗）与时间轴速记弹窗（.nmodal 自有规则）不受影响。build index-DFbwx_8z.js，部署备份 2026-09-09T06-49-49。

# 2026-09-09（二）：四模块合并工作台 /hub 落地 + desc 数据丢失修复（grill-me 六问决策）

## 访谈决策链（grill-me 六问闭环）

1. 优先级（用户排序）：产品合并 D > 表单统一 C > 编辑器协议 B > 止血 A——但 A 独立于形态，最先做。
2. 形态：Tab 型工作台（原型三变体竞标，B「概览优先」胜出）。不变量：4 表与 services/dashboard.ts 统计聚合零改动（用户红线：文章数据进云笺统计的链路不能受影响——实测统计在服务端按表聚合，与页面解耦，约束自动满足）。
3. 数据层：保持 4 表前端聚合，不合并单表（单表需重写 8 处 dashboard 查询+迁移，违背上述不变量）。
4. 范围：计划|目标|习惯|想法 4 Tab；速记汇总并入想法 Tab（同源同表 NoteItem，视图切换）；工作计划周视图/日常页/记账保留独立入口。
5. 命名：「灵感」更名「想法」——契合 NoteItem 状态机生命周期（pending 待使用→used 已使用）。
6. 路由：/hub?tab=today|plan|goals|checkin|ideas；旧路径 /plan /goals /checkin /notes /goals-home /quick-notes 全 Redirect；授权 scopes 粒度不变。防重蹈覆辙红线（用户：当年放一起不好用、现在太分散）：单一入口（全 Redirect 消灭双入口）、Tab 状态进 URL、编辑器从第一天就是统一协议。
