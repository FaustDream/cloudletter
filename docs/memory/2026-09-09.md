## 补充：编辑器高度改为填满表单+内部滚动（同日）

- 用户再反馈：随手记等编辑抽屉内容区较矮、下方大片空白。要求编辑器填满表单到底部分割线、内容超出时内部滚动。
- 实现（纯 CSS，:has() 项目已有使用）：.drawer-body:has(.mded) / .modal:has(.mded) 变纵向 flex；含编辑器的 .mfield:has(.mded) flex:1；高度链 .mded→.ed-blocknote→.bn-container 全 flex column min-height:0，.bn-editor flex:1 + overflow-y:auto（min-height 120 保底）。Modal 补 max-height calc(100vh-48px)+overflow:auto、.mh/.mfoot flex-shrink:0。
- 实测（Node 直驱 playwright-core）：随手记/计划抽屉空态编辑器 423px 恒定、底边距分割线 19px 不随内容变化；810 字输入内容高 547>423 时编辑器内部滚动、抽屉 body 不滚。Modal（工作计划）高度由内容决定时编辑器紧贴分割线（gap 23px=footer margin，无空白），超视口时 max-height+内部滚动兜底。
- 影响面：所有含编辑器的抽屉/弹窗（随手记/计划/目标/习惯/工作计划/速记汇总）；文章编辑页（非抽屉/弹窗）与时间轴速记弹窗（.nmodal 自有规则）不受影响。build index-DFbwx_8z.js，部署备份 2026-09-09T06-49-49。
