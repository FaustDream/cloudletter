# 2026-09-05（四）：侧边栏悬停抽屉重构 + 导览会话级弹出 + 「组织」更名「分类标签」

## 改动内容

### 1. 侧边栏悬停展开动画卡顿修复（commit 4f33939）

- 根因：原实现靠 React 切类名后 CSS `transition: width`（64px→264px）展开，width 是布局属性，动画期间每帧对侧边栏整棵子树重排（peek 首帧图标/文字还从隐藏切显示，跳变更明显），重页面（three/mermaid/BlockNote）主线程一忙就掉帧。
- 重构：图标轨道（`.sidebar.collapsed`）常驻不动；新增始终挂载的抽屉层 `<aside class="sidebar sb-drawer">`（含 brand + nav + sb-ctrl + sb-gh + foot，复用 memo 化的 `nav`），CSS 仅动画 `transform: translateX(-102%) ↔ 0`，由合成器线程执行、零重排。`visibility` 延迟 0.2s 切换保证滑出动画完整播放，隐藏后自动移出焦点序与无障碍树（`aria-hidden` 同步）。
- 交互坑位修复：程序化关闭（点击导航项、⌘B/按钮切换模式）后，指针若停在 64px 轨道上会因抽屉滑走触发一次"凭空"的 mouseenter 导致关了又弹——加 `closedAt` 时刻戳 + 450ms 抑制窗口（`closePeek`/`startPeek` 守卫）。
- 参数：hover intent 120ms→80ms；离开防抖 350ms 不变；抽屉 `prefers-reduced-motion: reduce` 降级为直切。常驻↔折叠切换仍走 width/margin-left（低频主动操作，未动）。

### 2. 能力导览（tips）会话级弹出（commit 5bedfbc）

- 新增 `apps/workbench/src/lib/tour.ts`：`cl_login_epoch` 登录会话标记（`api.setToken` 成功写 token 时统一写入，覆盖密码/两步验证/验证码全部登录路径；刷新页面不算重新登录）+ `cl_org_tour` 关闭记录（`{scope: 'session'|'forever', epoch}`）；旧 `cl_org_toured=1` 迁移为 forever。弹出判定 `shouldShowTour`：无记录→弹；forever→不弹；session 同 epoch→不弹、异 epoch（重新登录）→弹。

# 2026-09-05（五）：文章编辑页九项体验优化与 bug 修复

## 需求与决策（用户拍板）

1. **冲突策略 = 本地覆盖 + 首次轻提示**：编辑会话内自动保存遇乐观锁冲突（如另一标签页改过），自动以本地内容覆盖重试，不再弹「以本地为准覆盖 / 加载服务器版本」横幅；仅会话内第一次冲突给一条非阻断轻提示。
2. **重开取舍 = 服务器为主 + 一次性轻提示**：重开文章始终加载服务器版本；本机存在较新未同步草稿（断网/保存失败残留）时给一条可关闭的轻提示，可「恢复本机草稿」或「放弃并继续」，12s 未处理视为放弃并清理快照。移除旧的恢复横幅。
3. **大纲识别**：用户标题来源包括 `#` 语法/斜杠菜单、手写 `#标题`（无空格）、外部粘贴——据此放宽 `extractHeadings`（无空格、引用内标题、ATX 收尾均识别；5 个以上 `#` 仍排除、空标题不识别）。
4. **编辑态**：离开页面再回来仍是编辑页，且写一半的内容要能找回（= 离开 flush + 冲突策略保证落库 + 重开轻提示兜底）。
