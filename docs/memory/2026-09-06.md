## 总览四世界八项反馈修复（2026-09-06（三））

### 用户条目 → 落地

1. **删时光长河浮窗日期选择**：用户指的「浮窗选择日期」= 河面上悬浮常驻的「选择日期」胶囊（`.tb-jump-wrap`，portal 到 body、可拖拽换位、点击展开自绘月历），不是工具栏 RangePicker（范围选择保留，时间尺度档位也保留）。TimelineBubbles 整组删除（jumpDate/jumpCalOpen/jumpTo/jumpPos/拖拽 window 监听/`cl_tl_jump_pos` localStorage/Capsule+DateCal+todayYMD 导入/`active` prop），CSS 清 `.tb-jump*`/`.tb-day.jump-flash`/dayFlash keyframes/暗色主题引用。
2. **修滑到当天空白+卡死**：根因是 `days.length===0` 时（如「当天」档位当天无数据，后端只返回有节点的天）外层 EmptyState 替换掉了 `.river-scroll`，onRiverWheel（滚轮循环时间尺度）随之消失 → 无法滚回历史档位。修复：滚轮容器常驻，空态渲染在河面内，文案引导「滚轮或上方档位切回更大的时间尺度」。
3. **右上角经验/金币撤下**：OverviewPage HUD 的 XP 胶囊（LV/xpbar/XP）与金币胶囊删除，HUD 只留 AvatarMenu；hud useMemo 只留 xp/lv（升级检测与徽标仍用）。与（二）的「设置→游戏」开关合流：默认仅头像。
4. **神经转动粒子/陨石**：TimelineUniverse3d 渲染循环加 7 颗随机流星（LineSegments 头尾顶点 + AdditiveBlending，颜色乘亮度包络=透明度，尾端全黑隐形；出界/寿命尽重生）。尊重 reduced-motion（不加挂）与 degrade 帧控（heavy 帧才 update）。
5. **修监控 CPU/网络恒 0**：两处根因——① `/proc/net/dev` 正则多吞一列抓到 tx_packets（第 10 列）而非 tx_bytes（第 9 列），包数差值/1024 恒 0；② up/down 与 rx/tx 反接、前端 toFixed(0) 把 <0.5% 吞成 0。修复：正则改 7 列间隔、up=tx/down=rx、CPU 改跨请求长窗口差值采样（lastSample 基线，1~30s 窗口免二次采样；首采/回绕退回 120ms 双采样）、前端 toFixed(1) + 箭头对调。
6. **删神经左上角返回按钮**：`uni3d-back` 按钮与样式删除，`onBack` prop 移除；世界切换走顶部四世界导航（world-nav）。
7. **城市全屏化+小人**：`.city-stage` relative 容器（100dvh-200px 圆角边框）改 `fixed inset:0`，背景径向光斑放大；新增两只火柴人（SVG+CSS 动画）：计划区旁工人挥锤（cw-hammer 旋转 + 尘土脉冲）、底部行人穿城（cw-swing 四肢摆动 + cityWalk 平移 44s 循环），transform-box: view-box 定 transform-origin，reduced-motion 降级静立。顶栏 world-nav/tl-bar.sub 加 z-index:3 浮于全屏视图上；city-hud 上移避让左下角 FAB、zone-panel/core-hud-labels 下移避开顶栏。
