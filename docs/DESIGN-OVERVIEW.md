## 核心设计要点

- **架构形态**：单仓多包（server + apps/write + apps/console + e2e + fuwari-blog）+ 绞杀者模式。
- **分层**：客户端 / 静态站 / 网关反代 / API·BFF / 领域服务 / 持久化 / 构建发布 / 质量运维，共 8 层，单向依赖。
- **边界纪律**：前端↔后端仅经 HTTP `/api/v2`；`server` 为唯一 DB 与磁盘写方；跨包 import 禁止。
- **设计权限**：对全部源文件/目录完整覆盖；`fuwari-blog/` 为限定权限（第三方依赖态，不入门禁）；产物/数据目录排除。
- **标准符合**：三级严重级别、合并门槛（typecheck/test/lint/build）、RBAC 四级、错误包络、乐观锁、序列化往返契约，与 CODE_REVIEW.md 100% 对齐。

## 后续建议
