## 一、设计哲学

### 1.1 核心理念

本设计系统遵循 **"安静的工具，不打扰的陪伴"** 设计哲学。既不极简到冰冷，也不花哨到干扰效率。它在以下三者之间找到平衡：

- **高效工具感**：信息密度适中，常用功能一屏可见，无需频繁滚动或深入嵌套
- **温暖产品感**：柔和配色、圆角卡片、情感化微文案，让工具类产品不冰冷
- **渐进式复杂度**：默认只展示核心设置，高级选项通过展开/折叠按需呈现

### 1.2 风格定位一句话

**现代 macOS 系统设置风格 + Ant Design 5.0 克制感 + 消费级产品的微情感设计**

### 1.3 关键设计原则

| 原则 | 说明 |
|:---|:---|
| **卡片即模块** | 每个功能单元独立成白色卡片，视觉边界清晰，可独立理解 |
| **留白分割，非线条分割** | 模块之间靠间距区分，不依赖分割线 |
| **状态即时可见** | 开关、数值、时间戳等状态信息直接展示，不给用户猜的空间 |
| **操作就近放置** | 按钮、开关、输入框紧邻其描述文案，不跳转、不弹窗 |
| **线下安全感** | 显式声明"纯本地运行"，隐私声明放在显眼位置 |
| **情感但不打扰** | 彩色图标仅用于"支持与反馈"等非核心区，核心功能区保持克制的蓝色单色系 |

## 二、布局系统

### 2.1 全局框架

```
┌──────────┬──────────────────────────────────────────┐
│          │         顶部栏（Header）                   │
│ 侧边栏   ├──────────────────────────────────────────┤
│          │                                          │
│ 导航菜单  │         内容区（Content Area）            │
│          │    ┌────────────────────────────────┐    │
│          │    │  功能模块卡片 1                  │    │
│          │    └────────────────────────────────┘    │
│          │    ┌────────────────────────────────┐    │
│          │    │  功能模块卡片 2                  │    │
│          │    └────────────────────────────────┘    │
│          │    ┌────────────────────────────────┐    │
│          │    │  功能模块卡片 3                  │    │
│          │    └────────────────────────────────┘    │
│          │                                          │
│          │              页脚（Footer）               │
└──────────┴──────────────────────────────────────────┘
```

### 2.2 侧边栏（Sidebar）

- **宽度**：约 200-220px，窄侧边栏
- **背景色**：比内容区背景深半阶的浅灰 `#EBEDF0` 或直接与内容区同色 `#F0F2F5`
- **项目结构**：图标（20px 线性） + 文字标签（14px），垂直排列
- **项目间距**：菜单项之间约 8-12px 垂直间距
- **顶部留 Logo 区域**：侧边栏顶部可能有一个 Logo 或标题区

#### 2.2.1 菜单项状态规格

侧边栏导航菜单项有三种状态，通过背景色、文字色、字重区分：

```
未选中                         选中（激活）
┌──────────────────────┐      ┌──────────────────────┐
│  🖐  外观设置         │      │  🖐  手势功能         │  ← 浅蓝背景
│                      │      └──────────────────────┘
└──────────────────────┘
      灰色图标+文字              蓝色图标+文字+粗体
```

| 属性 | 未选中态 | 选中态（激活） |
|:---|:---|:---|
| **背景色** | 透明（跟随侧边栏背景） | `#EEF2FF` 浅蓝底 |
| **图标色** | `#86868B` 中灰 | `#1A73E8` 蓝色 |
| **文字色** | `#4E4E50` 深灰 | `#1A73E8` 蓝色 |
| **字重** | 400（Regular） | 600（Semi-bold） |
| **字号** | 14px | 14px |
| **形状** | 直角矩形，无圆角 | 直角矩形，无圆角 |
| **边框** | 无 | 无 |
| **左侧指示线** | 无 | 可选：左侧 2px 蓝色竖线 `#1A73E8`（高度与行高一致） |

> **设计意图**：选中态不使用卡片式圆角背景（区别于设置区卡片），而是用**直角矩形 + 浅蓝底色**，形成"导航项被点亮"的视觉效果。直角矩形在侧边栏中比圆角更稳定，也明确区分了"导航"与"内容卡片"两种不同的信息层级。

#### 2.2.2 菜单项悬停态

| 属性 | 值 |
|:---|:---|
| 背景色 | `#F5F5F7`（未选中项悬停）/ `#DDE7F5`（选中项悬停，略深于选中背景） |
| 文字/图标色 | 不变（保持当前状态的配色） |
| 光标 | `pointer` |

#### 2.2.3 完整菜单项 CSS

```css
.sidebar-item {
  display: flex;
  align-items: center;
  height: 40px;
  padding: 0 16px;
  font-size: 14px;
  font-weight: 400;
  color: #4E4E50;
  background: transparent;
  border: none;
  cursor: pointer;
  user-select: none;
}
.sidebar-item:hover {
  background: #F5F5F7;
}
.sidebar-item.active {
  background: #EEF2FF;
  color: #1A73E8;
  font-weight: 600;
}
.sidebar-item.active:hover {
  background: #DDE7F5;
}
.sidebar-item .icon {
  width: 20px;
  height: 20px;
  margin-right: 8px;
  flex-shrink: 0;
}

```

### 2.3 顶部栏（Header）

- **高度**：约 48-56px
- **背景**：白色或与内容区同色
- **内容**：居中显示应用名 "应用名 本设计系统 v2.2"（Logo + 版本号）
- **右侧操作区**：设置齿轮图标 + 其他图标按钮
- **底部边界**：无明显分割线，靠背景色差或极淡阴影区分

#### 2.3.1 版本标签

版本号以灰色圆角标签形式展示在应用名右侧：

| 属性 | 值 |
|:---|:---|
| 背景 | `#F0F0F0` |
| 文字色 | `#86868B` |
| 字号 | 11px |
| 字重 | 400 |
| 圆角 | 4px |
| 内边距 | 2px 6px |
| 与标题间距 | 6px |

#### 2.3.2 设置齿轮图标

位于顶部栏最右侧，是应用全局设置的入口：

| 属性 | 值 |
|:---|:---|
| **类型** | 线性图标（Stroke Icon），标准六齿齿轮 + 中心圆孔 |
| **描边宽度** | 2px ~ 2.5px，圆头端点（Round Cap） |
| **图标尺寸** | 24×24px |
| **可点击区域** | 40×40px（隐式按钮容器，背景透明，便于精确点击） |
| **颜色** | `#3A3F47` 深灰（略浅于纯黑，带极微冷调） |
| **悬停态** | 颜色过渡到 `#1A73E8` 蓝色（与侧边栏选中色一致），背景出现 `#F5F5F7` 圆形底 |
| **圆角** | 图标本身无圆角（齿轮矢量图形）；容器为直角矩形 |
| **与左侧元素间距** | 12px（与版本号标签之间） |
| **与右侧边界间距** | 16px |
| **垂直对齐** | 与标题文字居中对齐 |

```css
.header-settings-btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 40px;
  height: 40px;
  background: transparent;
  border: none;
  border-radius: 4px;
  cursor: pointer;
  color: #3A3F47;
  transition: color 0.15s ease, background 0.15s ease;
}
.header-settings-btn:hover {
  color: #1A73E8;
  background: #F5F5F7;
}
.header-settings-btn svg {
  width: 24px;
  height: 24px;
}
```

### 2.4 内容区（Content Area）

- **宽度**：自适应（侧边栏 + 内容区 = 全宽），内容区建议最大宽度约 700-800px 居中
- **内边距**：左右约 32-40px，上下约 24px
- **滚动**：内容区独立纵向滚动，侧边栏和顶部栏固定

### 2.5 页脚（Footer）

- **位置**：内容区最底部，所有功能卡片之后
- **内容**：版本号、隐私声明、教程/GitHub/关于链接、署名
- **对齐**：居中
- **字体**：小号、浅灰色
- **与上方间距**：约 40-48px

## 三、配色系统

### 3.1 基础色板

| 色阶 | 色值 | 用途 |
|:---|:---|:---|
| **页面背景** | `#F0F2F5` | 全局底色，浅灰带极微量蓝紫 |
| **卡片背景** | `#FFFFFF` | 所有功能模块卡片的底色 |
| **卡片边框** | `#E8E8EC` | 白色卡片在浅灰背景上的边界勾勒 |
| **侧边栏背景** | `#EBEDF0` 或 `#F0F2F5` | 比内容区略深或同色 |
| **输入框/次要按钮背景** | `#F5F5F7` | 禁用态、次按钮、输入框底色 |
| **开关关闭态** | `#D9D9D9` | 开关未激活时的背景 |
| **开关关闭态滑块** | `#FFFFFF` | 白色圆形滑块，带浅灰边框 |

### 3.2 语义色

| 语义 | 色值 | 用途 |
|:---|:---|:---|
| **主色 / Primary** | `#1677FF` (或 `#1890FF`) | 主按钮、开关开启态、选中态、链接、滑块激活轨道、导航高亮 |
| **主色悬停** | `#4096FF` | 按钮悬停、开关悬停 |
| **主色按下** | `#0958D9` | 按钮按下态 |
| **成功/安全** | `#52C41A` | 同步成功、已保存状态 |
| **警告** | `#FAAD14` | 警告条背景 `#FFFBE6`，警告图标/边框 |
| **危险/删除** | `#FF4D4F` | "恢复默认"等不可逆操作按钮 |
| **链接色** | `#1677FF` | 可点击的文字链接 |

### 3.3 文字色阶

| 层级 | 色值 | 用途 |
|:---|:---|:---|
| **一级文字** | `#1D1D1F` | 模块标题、卡片标题、重要标签 |
| **二级文字** | `#4E4E50` | 设置项标题、正文 |
| **三级文字** | `#86868B` | 辅助说明文字、禁用态标签 |
| **四级文字** | `#8C8C8C` 或 `#B0B0B5` | 页脚、版权、最低优先级的提示 |
| **占位文字** | `#BFBFBF` | 输入框 placeholder |

### 3.4 情感色（非核心区专用）

仅在"支持与反馈"等用户情感触达区域使用，核心功能区不使用多彩图标：

- **反馈/灯泡**：暖橙 `#FA8C16`
- **鼓励/爱心**：柔粉 `#EB2F96`
- **帮助/问号**：浅蓝 `#1677FF`

## 四、字体排版系统

### 4.1 字体族

```
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
             "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif;
```

优先使用系统原生字体栈，中文使用苹方或微软雅黑，保证各平台最佳渲染效果。

### 4.2 字号与行高层级

| 层级 | 字号 | 行高 | 字重 | 用途 |
|:---|:---|:---|:---|:---|
| **H1 - 页面标题** | 20px | 28px | 600 (Semi-bold) | 顶部栏应用名、少数大标题 |
| **H2 - 模块标题** | 16px | 24px | 600 (Semi-bold) | 卡片标题，如"外观设置""手势功能" |
| **H3 - 设置项标题** | 14px | 22px | 500 (Medium) | 卡片内各设置项的标题，如"显示手势轨迹" |
| **Body - 正文/标签** | 14px | 22px | 400 (Regular) | 表单标签、普通正文 |
| **Caption - 说明文字** | 12px | 20px | 400 (Regular) | 设置项下方的辅助描述文字 |
| **Micro - 微小文字** | 11px | 18px | 400 (Regular) | 时间戳、版本号、页脚版权等最次要信息 |

### 4.3 排版规则

- **标题与说明的间距**：标题下方跟说明文字时，间距约 4px（紧凑跟随关系）
- **同组标签**：同一设置项内的多个标签或控件，垂直居中对齐
- **数值与单位**：数值和单位之间无空格（如"20""10%"），紧贴展示
- **英文/数字**：在中文环境中，英文单词和数字前后保留半角空格（如"已保存 10:21:20"）
- **快捷键表示**：按键组合使用灰色圆角小方块包裹，如 `Shift` `Ctrl`，背景 `#F0F0F0`，圆角 4px

## 五、间距与留白系统

### 5.1 间距标尺

本设计系统采用 **4px 基准栅格**，所有间距为 4 的倍数：

| 间距名 | 值 | 使用场景 |
|:---|:---|:---|
| **XS** | 4px | 紧密关联元素（图标与文字、标签与数值） |
| **SM** | 8px | 同组内控件之间的水平间距（如开关与标签） |
| **MD** | 12px | 卡片内设置项之间的垂直间距 |
| **LG** | 16px | 模块内部各设置项组之间的间距 |
| **XL** | 24px | 卡片与卡片之间的垂直间距 |
| **2XL** | 32px | 内容区内边距（左右） |
| **3XL** | 40-48px | 最后一个模块与页脚之间的间距 |

### 5.2 卡片内边距

- **卡片 Padding**：上下 16-20px，左右 20-24px
- **卡片内标题到第一个设置项**：约 12-16px
- **设置项描述到下一个设置项标题**：约 16px

### 5.3 对齐规则

- **开关 + 标签**：开关在左，标签在右，水平间距 8px，整体左对齐
- **标签 + 输入框**：标签在左，输入框在右，间距 12px，整体左对齐
- **标签 + 下拉**：同上
- **标签 + 滑块**：标签在上，滑块在下（或标签在左、滑块在右横向排列），间距 8px
- **卡片标题栏**：图标（20px）在左 → 标题文字间距 8px → 右侧操作按钮（开关/展开）靠右对齐

## 六、阴影与边框系统

### 6.1 阴影

本设计系统整体偏向扁平化，阴影使用极其克制：

| 场景 | 阴影值 | 说明 |
|:---|:---|:---|
| **卡片浮起** | `0 1px 2px 0 rgba(0, 0, 0, 0.03)` | 极轻阴影，配合 `1px` 边框使用 |
| **下拉菜单浮层** | `0 4px 12px rgba(0, 0, 0, 0.08)` | 浮层组件使用稍重的阴影 |
| **模态弹窗** | `0 8px 30px rgba(0, 0, 0, 0.12)` | 全局最重阴影，用于模态阻断的悬浮感 |
| **无阴影** | — | 页面背景、侧边栏、顶部栏、页脚均无阴影 |

**关键特征**：卡片主要靠 `1px solid #E8E8EC` 边框 + 极淡阴影组合来区分层次，而非依赖大范围投影。这比纯投影更精致、更"安静"。

### 6.2 边框

| 场景 | 边框值 |
|:---|:---|
| 卡片边框 | `1px solid #E8E8EC` |
| 输入框边框 | `1px solid #D9D9D9` |
| 输入框聚焦 | `1px solid #1677FF` + `box-shadow: 0 0 0 2px rgba(22,119,255,0.15)` |
| 次按钮边框 | `1px solid #D9D9D9` |
| 开关关闭态边框 | 无边框（靠背景色区分） |

### 6.3 分割线

**原则上不使用水平分割线**。模块和设置项之间完全通过卡片边界 + 间距留白来区分。特殊情况下（如数据管理模块的按钮区与文字区之间）可用 `1px solid #F0F0F0` 的极淡分割线。

## 七、图标系统

### 7.1 风格

- **类型**：线性图标（Line Icons / Stroke Icons）
- **描边宽度**：1.5px（推荐）或 2px（最大），保持纤细轻盈
- **端点**：圆头（Round Cap）+ 圆角连接（Round Join）
- **风格参考**：接近 Ant Design Icons / Phosphor Icons / Feather Icons

### 7.2 尺寸与颜色

| 位置 | 尺寸 | 颜色 |
|:---|:---|:---|
| 侧边栏菜单图标 | 20×20px | `#86868B`（未选中）/ `#1677FF`（选中） |
| 模块标题左侧图标 | 20×20px | `#1677FF`（蓝色圆形或圆角方形底 + 白色图标） |
| 设置项内辅助图标 | 16×16px | `#8C8C8C` |
| 顶部栏操作图标 | 18-20px | `#4E4E50` |
| 情感区图标 | 20×20px | 对应情感色（橙/粉/蓝） |

### 7.3 模块标题图标规范

这是特色——每个功能模块卡片标题左侧有一个**蓝色背景的圆角方形图标容器**：

```
┌─────────────────────────────────────────────┐
│  🔵 外观设置                          [开关] │  ← 蓝底白图标 + 标题文字
│                                             │
│     显示手势轨迹                    [开关]   │
│     ...                                     │
└─────────────────────────────────────────────┘
```

- **容器**：24×24px 或 28×28px 圆角方形（圆角 6px），背景 `#1677FF`
- **内部图标**：16×16px 白色线性图标
- **与标题间距**：8px
- **垂直对齐**：与标题文字垂直居中

## 八、组件库规格

### 8.1 开关（Toggle Switch）

本设计系统最核心的交互组件，用于所有布尔型设置。

```
关闭态:  ┌──────┐
         │  ○  │  灰色轨道 #D9D9D9
         └──────┘
开启态:  ┌──────┐
         │●●○  │  蓝色轨道 #1677FF
         └──────┘

### 8.10 弹窗（Modal Dialog）

弹窗采用**轻量、无标题栏、居中布局**的设计，与主界面圆润柔和的语言高度一致。弹窗不使用传统的横条标题栏 + 右上角 X 按钮，而是通过图标 + 标题 + 描述 + 操作按钮的垂直流式布局来组织信息，配合点击遮罩和 ESC 键关闭。

#### 8.10.1 弹窗整体结构

```
┌─────────────────────────────────────────────────┐
│               [半透明模糊遮罩]                     │
│                                                 │
│       ┌─────────────────────────────┐           │
│       │  (padding: 32px 40px)       │           │
│       │                             │           │
│       │         [图标 48px]          │  ← 居中  │
│       │                             │           │
│       │       无法使用手势            │  ← 标题  │
│       │                             │           │
│       │  此页面由于浏览器安全限制，    │  ← 描述  │
│       │  扩展程序无法加载             │           │
│       │                             │           │
│       │  ┌───────────────────────┐  │           │
│       │  │  ⓘ  了解详情           │  │  ← 按钮  │
│       │  └───────────────────────┘  │           │
│       │                             │           │
│       └─────────────────────────────┘           │
│                                                 │
└─────────────────────────────────────────────────┘
```

#### 8.10.2 遮罩层（Overlay / Backdrop）

| 属性 | 值 |
|:---|:---|
| 定位 | `position: fixed; inset: 0;` |
| 背景色 | `rgba(255, 255, 255, 0.85)` 白色半透明 |
| 模糊效果 | `backdrop-filter: blur(4px)` 轻微高斯模糊 |
| 层级 | `z-index: 1000` |
| 交互 | 点击遮罩关闭弹窗 |

**设计意图**：与常见的黑色半透明遮罩不同，本设计系统使用**白色半透明 + 模糊**，让弹窗浮现时主界面只是"柔和退后"而非"被黑暗吞没"，保持轻盈感。这与 macOS 的毛玻璃设计语言一脉相承。

#### 8.10.3 弹窗容器

|:---|:---|

#### 8.10.5 弹窗类型与变体

| 类型 | 图标 | 图标色 | 典型标题 | 按钮文案 |
|:---|:---|:---|:---|:---|
| **错误/限制提示** | 禁止 ⛔ | `#FF4D4F` | 无法使用手势 | 了解详情 |
| **信息确认** | 信息 ℹ️ | `#1677FF` | 操作已保存 | 知道了 |
| **危险确认** | 警告 ⚠️ | `#FAAD14` | 恢复默认设置？ | 确认恢复 / 取消（双按钮） |
| **成功反馈** | 勾选 ✓ | `#52C41A` | 导入成功 | 好的 |

> **双按钮布局**：当需要确认/取消两个操作时，两个按钮水平排列，均宽 100%，间距 12px。主操作按钮（如"确认恢复"）使用危险色 `#FF4D4F`，次操作按钮（如"取消"）使用白色 `#FFFFFF` + 边框 `1px solid #D9D9D9`。

#### 8.10.6 关闭方式

| 方式 | 行为 |
|:---|:---|
| 点击遮罩 | 关闭弹窗（不执行操作） |
| 按 ESC 键 | 关闭弹窗（不执行操作） |
| 点击操作按钮 | 执行对应操作后关闭弹窗 |

**注意**：本设计系统弹窗**没有右上角 X 关闭按钮**。这是有意为之——减少视觉噪音，同时引导用户通过遮罩点击或按钮交互来关闭，而非在多处提供关闭入口造成混乱。

#### 8.10.7 弹窗与主界面的视觉关系

- **对比度控制**：弹窗背景 `#F5F7FA` 比遮罩下的主界面略亮，形成"浮起"的视觉层次
- **品牌一致性**：弹窗圆角（16px）是全局最大圆角，与卡片（12px）、按钮（6px）形成层级递进关系——圆角越大，层级越高
- **阴影语言**：弹窗阴影 `0 8px 30px` 是全局最深阴影，用于强调"模态阻断"的语义
- **色彩克制**：弹窗内部以灰白为主，仅图标和主按钮带语义色，不喧宾夺主

    └── 鼓励我们          ─ 链接卡片
```

### 9.2 信息组织原则

1. **首页聚合**：设置概览页展示所有核心模块的标题 + 总开关，用户无需深入即可掌握全局状态
2. **二级展开**：每个模块的详细设置在卡片内通过"显示高级设置"开关按需展开，避免信息过载
3. **独立模块**：特殊功能（黑名单、数据管理等）作为独立卡片排在下方
4. **页脚收尾**：支持信息、版本号等放在最后，降低视觉权重
5. **模块排序**：高频功能在上（外观、手势、拖拽），低频功能在下（数据管理、黑名单），情感功能在最后

### 9.3 一屏可见原则

默认状态下一个屏幕内应能看到 3-5 个核心模块卡片，无需滚动即可概览全局。高级设置展开后允许超出屏幕高度。

## 十、交互模式与设计惯例

### 10.1 开关交互

- **即时生效**：开关切换后设置立即生效，不需要点击"保存"按钮
- **无确认弹窗**：普通开关操作不需要二次确认
- **仅有风险操作需确认**：如"恢复默认"（红色按钮）需要弹窗确认

### 10.2 渐进式披露（Progressive Disclosure）

```
默认视图                展开视图
┌──────────────┐      ┌──────────────┐
│ 手势功能 [开关]│      │ 手势功能 [开关]│
│              │  →   │              │
│ 显示高级设置  │      │ 显示高级设置  │
└──────────────┘      │ 触发按钮 ...  │
                      │ 判定距离 ...  │
                      │ 转向容差 ...  │
                      └──────────────┘
```

- 高频基础设置直接可见
- 低频高级设置默认隐藏，通过"显示高级设置"开关展开
- 展开/折叠带平滑过渡动画（max-height 或 height 过渡）

### 10.3 数值调整交互

滑块的使用模式：

- **拖拽为主**：用户拖动滑块圆点调整数值
- **点击轨道**：点击轨道任意位置，滑块跳转到对应位置
- **刻度辅助**：刻度点提供视觉参考，帮助用户感知量级
- **数值即时显示**：当前值在标签旁实时显示，无需额外查看

### 10.4 快捷键编辑交互

- 修饰键组合以 Keycap 方块可视化展示
- 点击可进入编辑模式（或通过下拉切换键位）
- 加号按钮（+）用于添加新的组合快捷键

### 10.5 反馈时效

## 附录：设计决策 FAQ

**Q: 为什么卡片不用大阴影？**
A: 工具类产品需要"安静"，大阴影会抢注意力。用 `1px` 极淡边框 + 微阴影，层次足够且不喧闹。

**Q: 为什么不用分割线？**
A: 分割线是"硬"分割，留白是"软"分割。本设计系统追求柔和的视觉感受，卡片自身就是最强的视觉边界。

**Q: 什么场景下可以用分割线？**
A: 只在同一个卡片内部、两个逻辑差异很大的区域之间（如数据管理模块的状态文字区和操作按钮区），可以用 `1px solid #F0F0F0` 的极淡线。

**Q: 情感图标可以用在核心功能区吗？**
A: 不可以。核心功能区保持蓝色单色系，彩色图标仅限于"支持与反馈""鼓励我们"等用户情感触达区域。这是克制感的关键。

**Q: 开关和复选框如何选择？**
A: 单个独立功能的布尔状态用开关；多个并列选项的多选用复选框组。
