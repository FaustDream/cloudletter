# Markdown 语法速查

这里整理了博客写作时最常用到的 Markdown 语法，基本都能被本站正常渲染。

## 文本样式

- **加粗**：`**加粗**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`
- `行内代码`：`` `行内代码` ``
- [链接](https://www.codebuddy.ai) 与 <https://www.codebuddy.ai> 自动链接

## 表格

| 语法 | 用途 | 优先级 |
|:-----|:----:|------:|
| `**` | 加粗 | 高 |
| `*` | 斜体 | 中 |
| `~~` | 删除线 | 低 |
